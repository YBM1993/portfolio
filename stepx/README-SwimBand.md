# SwimBand — первая версия

Сайт: https://ybm1993.github.io/portfolio/stepx/

## Что умеет
Имя пловца, стиль и дистанция; ручной старт и финиш через BLE;
измерение времени на XIAO nRF52840; история в текущем браузере; выгрузка CSV.
Деморежим работает без платы, считает время на сайте и хранит записи отдельно.
Выбранная дистанция записывается вручную: плата её не измеряет.

## 1. Прошивка в Arduino IDE
1. Скачайте SwimBandBracelet.ino рядом с этим файлом.
2. В Arduino IDE → File / Файл → Preferences / Настройки добавьте URL менеджера плат:
   https://files.seeedstudio.com/arduino/package_seeeduino_boards_index.json
3. В Boards Manager установите **Seeed nRF52 mbed-enabled Boards**.
4. Выберите Seeed XIAO BLE для обычной nRF52840 или Seeed XIAO BLE Sense для Sense
   (точное название зависит от версии пакета). Нужен именно пакет mbed-enabled.
5. В Library Manager установите **ArduinoBLE** от Arduino.
6. Откройте .ino. Если IDE предложит создать папку SwimBandBracelet — согласитесь.
7. Подключите плату USB-кабелем передачи данных, выберите порт и нажмите Upload / Загрузить.
   Если порт не виден, дважды быстро нажмите Reset на плате и выберите появившийся порт.
8. Монитор порта: 115200. Ожидаемое сообщение: SwimBand ready.
Старая прошивка StepX для шагов несовместима с этой версией сайта.
Датчик IMU для ручного секундомера не используется.

## 2. iPhone
1. Установите Bluefy: https://apps.apple.com/app/id1492822055
2. В Bluefy откройте https://ybm1993.github.io/portfolio/stepx/
3. Включите Bluetooth, разрешите доступ Bluefy по запросу.
4. Оставьте плату подключённой к USB для первого теста.
5. В режиме «Браслет» нажмите «Подключить браслет» и выберите XIAO SwimBand.
Обычный Safari на iPhone не предоставляет Web Bluetooth для такого подключения.
Устройства рядом с телефоном выбираются в самом сайте, сопряжение в настройках обычно не требуется.

## 3. Проверка на столе
1. Введите имя, стиль и дистанцию.
2. Нажмите «Старт», подождите несколько секунд, нажмите «Финиш».
3. Проверьте время и строку истории.
4. Повторите с другим именем. Скачайте CSV.
5. Во время отдельного тестового заплыва отключите Bluetooth, сохранив питание платы.
   Включите Bluetooth и подключите ту же плату: сайт должен восстановить секундомер.
6. После перезагрузки страницы подключитесь снова. Завершённый ожидающий результат
   должен сохраниться один раз.
Проверка экрана без платы: «Демо без платы». Это не проверка настоящего BLE.

## Как сохраняется результат
Старт и финиш происходят при получении команд платой, поэтому задержка Bluetooth и
реакция человека влияют на измерение. Это тренировочный прототип, не система
официального хронометража. Телефон показывает текущее время между сообщениями платы;
в историю попадает итоговое время, переданное платой.
Имя, стиль и дистанция закрепляются при старте.
Повторная команда финиша не меняет уже полученное время.
При переподключении сайт читает состояние и восстанавливает незавершённый заплыв.
Если на плате идёт заплыв, начатый в другом браузере, можно заполнить данные и нажать
«Финиш», чтобы связать результат с ними. Не пользуйтесь несколькими телефонами одновременно.

## Ограничения
- Не определяет повороты, гребки, бассейны и стиль автоматически.
- Максимальное время одного заплыва — 24 часа, затем автоматический финиш.
- Последний результат и активный секундомер хранятся в оперативной памяти платы:
  выключение или сброс платы их удаляют. Сохранённая история сайта остаётся.
- История доступна в том же браузере на том же устройстве. Очистка данных браузера
  удалит её; экспортируйте CSV. Общей базы, аккаунтов и синхронизации между учениками нет.
- BLE не гарантирует связь под водой. Для первого теста держите плату и телефон на столе.
  Плата без герметичного корпуса не предназначена для погружения.
- Закрытая вкладка и заблокированный экран могут отключить BLE. Держите страницу
  открытой; если связь потерялась, восстановите её при сохранённом питании платы.
- Прошивку следует собрать в Arduino IDE под выбранную модель и проверить на своей плате.

## Протокол v1
Service: 12345678-1234-5678-1234-56789abcdef0
Telemetry Read + Notify: 12345678-1234-5678-1234-56789abcdef1
Command Write: 12345678-1234-5678-1234-56789abcdef2

Телеметрия: W<состояние>:<ID 8 HEX>:<миллисекунды 8 HEX>, ровно 20 ASCII байт.
Состояния: I — ожидание, R — отсчёт, F — финиш.
Старт G:XXXXXXXX, финиш F:XXXXXXXX, где XXXXXXXX — ненулевой ID заплыва.
Команды повторяемы: повтор того же старта не обнуляет время, повтор финиша не изменяет его.
Ошибки: E:COMMAND, E:BUSY, E:RUN. Следующее сообщение содержит обычное состояние.

Официальная настройка платы: https://wiki.seeedstudio.com/XIAO_BLE/
